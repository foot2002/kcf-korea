# 콘텐츠 관리 안내

이 문서는 사이트에 올라가는 공지, 소식, 교육, 기관 목록을 고치는 방법입니다. 비밀번호는 쓰지 않습니다. GitHub 토큰으로 로그인합니다.

## 1. 토큰 만들기

1. GitHub에 로그인합니다.
2. 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token 을 엽니다.
3. 저장소는 `foot2002/kcf-korea` 하나만 고릅니다.
4. 권한은 Contents 의 Read and write 만 켭니다. 다른 권한은 켜지 않습니다.
5. 만료는 90일로 둡니다.
6. 만들어진 토큰은 그 화면에서 한 번만 보입니다. 비밀번호 관리 도구에 적고, 채팅이나 문서에는 붙이지 않습니다.

## 2. 로그인

1. 사이트 주소 뒤에 `/admin` 을 붙여 엽니다.
2. GitHub 토큰 칸에 토큰을 넣고 로그인합니다.
3. 저장소에 글을 올릴 권한이 있으면 오른쪽 위에 GitHub 로그인 이름이 나옵니다.
4. 토큰은 이 브라우저 탭을 쓰는 동안에만 남습니다. 브라우저를 닫으면 사라집니다.
5. 일을 마치면 로그아웃을 누릅니다.

## 3. 탭에서 고치기

한 번에 한 종류만 저장합니다. 칸 옆에 빨간 문장이 나오면 그 칸을 고친 뒤 다시 저장합니다.

- 공지사항: 제목, 날짜(`2026-11-06`처럼), 링크, 본문, 공개 여부
- 소식·자료: 유형(보도자료, 보고서·자료, 관련 보도, 보도참고), 제목, 날짜, 출처, 기사 주소, 첨부 경로, 공개 여부
- 교육·웨비나: 교육 제목과 날짜, 전체 영상 번호, 세션별 영상 번호와 시작 초, 자료의 공개 여부와 파일 경로, 참여 인원 표기
- 실천·우수기관: 기관명, 구분, 인증번호, 선정일, 선정 이유, 인증서 경로, 상태, 공개 여부. 인증번호 새로 만들기를 누르면 `SURE-연도-네 자리`가 겹치지 않게 채워집니다. 만료일은 없습니다.
- 실천선언 참여 기관: 기관명, 선언일, 공개 여부. 한 곳 이상 공개하면 무상제공 페이지의 실천선언에 기관명이 나옵니다.
- 성과 수치: 라벨과 값. 재단 메인 숫자 띠에 쓰입니다.

날짜는 `연-월-일`입니다. 주소는 `https://` 로 시작합니다. 비워 둘 수 있는 칸은 비워도 됩니다.

## 4. 저장한 뒤

저장을 누르면 그 탭의 내용이 GitHub `main` 브랜치의 `public/content` 파일로 올라갑니다. 커밋 링크가 보입니다.

사이트에 보이기까지 1~2분 걸립니다. 배포가 끝난 뒤 페이지를 새로고침합니다.

그 사이에 다른 사람이 같은 파일을 고쳤으면 “다른 관리자가 먼저 수정했습니다”가 나옵니다. 최신 내용을 불러온 뒤 다시 고치고 저장합니다.

## 5. PDF와 이미지

관리 화면에서는 파일을 올리지 않습니다.

1. GitHub에서 `foot2002/kcf-korea` 저장소를 엽니다.
2. `public/downloads` 폴더로 들어갑니다.
3. Add file → Upload files 로 PDF나 이미지를 올립니다.
4. 올라간 경로를 관리 화면의 파일 경로 칸에 적습니다. 예: `downloads/research/보도자료.pdf`
5. 그 탭에서 저장을 누릅니다.

## 6. 토큰이 새어 나갔을 때

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. 그 토큰을 열어 Delete 합니다. 지운 토큰은 바로 쓸 수 없습니다.
3. 새 토큰을 만들어 다시 로그인합니다.
4. 토큰을 메신저, 메일, 문서, 화면 캡처에 남기지 않습니다.
